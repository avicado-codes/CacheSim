CLI Invocator & Offline Execution

Offline Transport A Principle: The web viewer does not execute cache simulation logic in JavaScript. Execute the C++ binary in your terminal using the parameters configured above to generate official results.
ccsim simulate --trace demo_b.trace --l1 size=32KiB,line=64,ways=8,policy=lru,latency=4 --l2 size=256KiB,line=64,ways=8,policy=lru,latency=12 --memory-latency 200 --format json --output run.json
Offline Mode: Run the command above in your terminal, then load the generated run.json file to populate Analytics and Visualizer.
